## Featured Projects

### [SceneTrace_AI](https://github.com/NYN-05/SceneTrace_AI)

Semantic search for recorded video. The indexing pipeline samples frames, generates CLIP embeddings, Florence-2 captions, and YOLO-World object detections, then stores them in FAISS indexes. A hybrid ranking layer combines semantic, caption, object, and temporal signals to return timestamped clips with an explanation.

**Stack:** Python, FastAPI, CLIP, Florence-2, YOLO-World, FAISS, React

### [VERISIGHT_V1](https://github.com/NYN-05/VERISIGHT_V1)

Image authenticity verification. CNN, ViT, GAN, and OCR adapters score independent forensic signals; a weighted fusion model combines them into a calibrated authenticity score and an approve/review/reject decision. Served through a FastAPI backend with a React interface.

**Stack:** Python, PyTorch, FastAPI, React, OpenCV, OCR

### [Video KYC Deepfake Detection](https://github.com/NYN-05/Major_project)

Deepfake detection for low-resolution video KYC. A four-stage pipeline combines face-aware frame sampling, rPPG physiological signals, ResNet50 visual features, and a hybrid quantum-classical classifier with QAOA-based feature selection. Trained and evaluated on DFDC.

**Stack:** Python, PyTorch, OpenCV, MediaPipe, YOLO, PennyLane
